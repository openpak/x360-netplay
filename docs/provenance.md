# Provenance

Evaluation fork of [Xenia Web Services](https://github.com/AdrianCassar/Xenia-WebServices) under its existing MIT license. It is not an active OpenPak service: it uses an emulator-specific REST API, while OpenPak serves one native Xbox 360 backend for consoles and Wharf. Policy: [OPENPAK.md](../OPENPAK.md).
